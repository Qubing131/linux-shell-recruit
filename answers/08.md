# Task 08 Answer

请在这里简短回答：为什么 Shell 中 `$var` 和 `"$var"` 有时会产生不同的结果？

在普通命令参数中，未加引号的 `$var` 展开后可能按空格拆成多个参数；`"$var"` 会把展开结果作为一个参数保留。

例如文件路径是 `data/files/My Report.txt`，不加引号可能被拆成 `data/files/My` 和 `Report.txt`，导致 `cp` 找不到文件。因此复制时使用 `"$file"` 和 `"$destination/"`。

遍历多个文件参数时使用 `"$@"`：它保留每个参数的边界，所以带空格的文件名仍是一个参数，同时也能逐个处理多个文件。

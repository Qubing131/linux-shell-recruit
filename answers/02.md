# Task 02 Answer

请在这里回答题目中的两个问题。
1. `./tools/recruit-info` 给出了从当前目录出发的文件路径，所以 Shell 能找到它。只输入 `recruit-info` 时，Shell 会在 `PATH` 列出的目录中搜索；原先 `tools` 不在其中，因此找不到。文件还需要有执行权限才能运行，我用 `chmod +x tools/recruit-info` 添加了该权限。

2. 输入 `ls` 时，Shell 会沿着 `PATH` 中的目录查找名为 `ls` 的可执行程序，找到后运行。可以用 `command -v ls` 查看实际找到的位置。

我使用 `export PATH="$PWD/tools:$PATH"` 将仓库里的 `tools` 目录临时加入当前 Shell 的搜索路径，随后可以直接运行 `recruit-info`。
